# 💻 Личная панель управления (Dashboard)

Интерактивное веб-приложение, созданное для демонстрации навыков веб-разработки. 

## ⚡ Функционал
- Переключение тем оформления (светлая/темная) прямо в браузере.
- Интерактивная смена статусов по клику.
- Современный адаптивный дизайн с использованием CSS Grid и Flexbox.

## 🛠 Технологии
- **HTML5** — структура
- **CSS3** — стили, анимации и темы
- **JavaScript** — логика и интерактивность
